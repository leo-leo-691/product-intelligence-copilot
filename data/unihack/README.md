# Official UniHack files

Drop official challenge workbooks here, or upload them on **UniHack Evaluation**.

`official_expected_output.csv` is a cache of the published Expected Output sheet
and is the source of delivery headers. Header names are not hardcoded in app logic.

Optional: sample input, manufacturer list, LOV, UOM. Missing reference files do
not block output generation; unmatched fields stay blank.

This is **not** the 26-product Product Intelligence Copilot demo dataset.
